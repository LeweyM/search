# Making Regex from Scratch in Go

This branch contains one version of the regex engine built in the [Making Regex from Scratch in Go](https://lewismetcalf.com/series/making-regex-from-scratch-in-go/) series.

Each tutorial milestone has its own branch (`v1` through `v10`), so the files at the root are the complete snapshot for that chapter.

Run the tests with:

```sh
go test ./...
```
